# Projeto Vendas BI

Dashboard de vendas feito no Power BI com dados fictícios de uma rede de lojas.

![Visão geral do dashboard](imagens/visao-geral.png)

## O que o projeto mostra
- Faturamento, lucro, ticket médio e número de pedidos
- Análise por filial, cliente, produto e vendedor
- Comparação de metas e evolução ao longo do tempo

## Dados
Base fictícia (2023–2026) com cerca de 24 mil linhas de venda, 2 mil clientes,
60 produtos e 7 filiais. Os dados foram gerados aleatoriamente.

## Modelo de dados
Esquema estrela: a tabela Vendas no centro, ligada às tabelas
Calendario, Produtos, Clientes e Vendedores. Filiais liga a Vendedores e a Metas.

## Medidas DAX principais
Faturamento, Lucro, Margem %, Ticket Médio, Nº de Pedidos, Clientes Ativos

## Como abrir
1. Baixe o arquivo `.pbix`
2. Abra no Power BI Desktop (gratuito)
